# BIBLIA NARRACJI DOKUMENTALNEJ YOUTUBE

To jedyna aktualna Biblia produkcji tekstów. Wersja warsztatowa rozwijana dla Narrative V2 zastępuje dawny osobny folder `Produkcja tekstów/biblia`. Materiały o nagraniu, montażu i publikacji zachowano jako [notatki pomocnicze](../../Materiały%20warsztatowe/README.md), bez odrębnego pipeline.

Biblia jest zapleczem wiedzy dla Systemu v7.0. Tłumaczy, dlaczego dobre decyzje działają i jak stosować warsztat filmu dokumentalnego w długim formacie YouTube.

## Czego Biblia nie robi

Biblia nie określa:

- kolejności etapów,
- właścicieli,
- nazw plików,
- statusu projektu,
- liczby obowiązkowych audytów,
- progów bramek.

Te informacje istnieją wyłącznie w `_SYSTEM/`.

## Jak korzystać

- W0/K0 oraz K2/K2B mogą sięgać do właściwych rozdziałów Biblii przy projektowaniu filmu.
- K4 i K5 używają Biblii jako zaplecza kryteriów redakcyjnych, nie jako zamiennika dowodów.
- K3 **nie czyta automatycznie pełnych rozdziałów Biblii**. Dostaje wyłącznie skompilowany `_SYSTEM/NARRATIVE/K3-RULES-CORE.md`, zatwierdzony voice profile, Story Spine i packet bieżącego aktu.
- Przy sporze etycznym orkiestrator wraca do `03` i `05`, a wynik kompiluje do konkretnej decyzji K2/K4 zamiast dodawać kolejne ogólne nakazy autorowi.

Biblia jest źródłem warsztatowym dla kompilatora K2/K4. Nie jest rosnącym promptem i nie może zwiększać liczby twardych ograniczeń K3 poza zamkniętym constraint ledgerem.

## Źródła warsztatu

Biblia syntetyzuje:

- Michael Rabiger, Courtney Hermann — *Directing the Documentary*, 7. wyd.
- Sheila Curran Bernard — *Documentary Storytelling*, 3. wyd.
- Bill Nichols, Jaimie Baron — *Introduction to Documentary*, 4. wyd.
- Robert McKee — *Story*.

Mapę rozdziałów i zastosowań zawiera `12-BIBLIOTEKA-KSIAZEK.md`.

## Zasada adaptacji

YouTube nie unieważnia zasad dokumentu. Narracja musi jednak szybko ustanowić pytanie, regularnie zmieniać stan widza i brzmieć naturalnie w mowie. Klasyczny warsztat należy skrócić i zautomatyzować, ale nie zastępować tempem bez sensu ani pewnością większą niż pozwalają źródła.
