# USTALENIA STYLU — PAMIĘĆ KANAŁU

Ten plik przechowuje wyłącznie powtarzalne, jawnie zaakceptowane decyzje Dawida. Nie zapisuje pojedynczych poprawek bez szerszej wartości.

Nie jest bezpośrednim promptem K3. Zatwierdzone decyzje są kompilowane do wersjonowanego VOICE PROFILE; do packetu trafiają VOICE RULES i dosłowne, zatwierdzone VOICE EXEMPLARS. Reguła nie może wprowadzać celu liczbowego kontaktów, humoru, twistów, długości zdań ani słów w akcie.

## Format wpisu

```text
DATA:
KANAŁ:
DECYZJA:
PRZYKŁAD DOBRY:
PRZYKŁAD ZŁY:
POWÓD:
POTWIERDZONE W PROJEKTACH: [minimum 2 dla stylu; 3 dla danych]
```

## Zasady bazowe

- Naturalny język mówiony jest ważniejszy niż literacka symetria.
- Tajemnica dostaje najlepszą uczciwą wersję przed kontrargumentem.
- Finał nie powinien stawać się wykładem metodologicznym bez emocji.
- Humor nie może wykonać pracy argumentu.
- Konkretny obraz i działanie są preferowane wobec abstrakcyjnego komentarza.
- Kontakt z widzem i humor występują tylko wtedy, gdy mają nazwaną funkcję; zero obu jest legalne.
- Dokładny AUTHOR_TEXT pozostaje dosłowny. Model nie parafrazuje go ani nie tworzy autorskiego „ja” za Dawida.
