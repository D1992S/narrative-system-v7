## Reguła aktualizacji

- WPM = słowa finalnego tekstu / minuty czystej narracji.
- Po trzech filmach używa się mediany, nie średniej.
- Po każdym kolejnym filmie przelicza się medianę z ostatnich pięciu porównywalnych materiałów.
- Inny format lub sposób prowadzenia może wymagać osobnego profilu.
